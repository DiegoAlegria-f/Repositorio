# Repositorio
Cibre Seguridad, proteccion de los datos y usuarios

**Hipótesis:**

La implementación de medidas de ciberseguridad, como el uso de contraseñas seguras, la autenticación multifactor, los antivirus, los firewalls y la capacitación de los usuarios, permitirá reducir los riesgos de ataques informáticos, accesos no autorizados y robo de información, mejorando la protección de los datos y los sistemas de una organización.
