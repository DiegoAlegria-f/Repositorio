# Repositorio
Cibre Seguridad, proteccion de los datos y usuarios

**Hipótesis:**

La implementación de un sistema integral de ciberseguridad, basado en el uso de contraseñas seguras, autenticación multifactor, firewalls, antivirus, actualizaciones de software, copias de seguridad y capacitación de los usuarios, contribuirá a disminuir las vulnerabilidades de los sistemas informáticos y el riesgo de incidentes de seguridad, como el robo de información, el acceso no autorizado y los ataques de phishing. Como resultado, se espera mejorar la confidencialidad, integridad y disponibilidad de la información dentro de una organización.

¿Qué significa esta hipótesis?
La hipótesis plantea que, si una organización aplica medidas de seguridad informática de manera adecuada, puede reducir los riesgos que amenazan sus sistemas y su información.
Por ejemplo, una empresa que no actualiza sus computadoras, utiliza contraseñas débiles y no cuenta con copias de seguridad puede ser más vulnerable ante determinados ataques informáticos. En cambio, si implementa controles de seguridad y capacita a sus trabajadores, puede prevenir algunos incidentes y responder mejor cuando ocurran.
